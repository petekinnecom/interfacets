# Interfacets

Rails on the server, Ruby in the browser, React for rendering.

Using WebAssembly to run [MRuby](https://mruby.org/) in the browser, Interfacets allows you to share both state and behavior seamlessly between frontend and backend. Declare the schema and behaviors of an object that you need on the frontend. Fulfill the schema on the backend. Build your React frontend from the comfort of Ruby. Let interfacets handle the rest.
