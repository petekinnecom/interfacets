# Interfacets Demo App

To run the server:

`bin/rails s -p 3005`

To compile the assets:

`npm run build --watch`

To run tests:

`bin/rails test` (runs all tests)
`bin/rails test:system` (runs browser integration tests)
`bundle exec ruby -I ./test test/users_show_test.rb` (runs specific facet unit tests)
